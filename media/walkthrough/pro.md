## Pro tools

The Pro tools run inside a free 14-day trial that starts the first time you use one. The trial is recorded only on this computer and needs no account, key or network.

* **Create Test File**: invented entries for PPD, CCD, CTX, WEB or TEL with correct totals, entry hash, check digits and filler.
* **Anonymise File** and **Anonymise Folder**: names, accounts, identifications and routing numbers replaced consistently; the controls are adjusted, so a correct file stays correct.
* **Recompute Control Records And Padding**: shows the difference first, applies only after you confirm.
* **Compare With Another File**: batches and entries matched, every difference listed.
* **Export Entries As CSV / JSON**, **Create Reconciliation Report For A Folder**, **Split Into One File Per Batch**, **Merge Files**.

After the trial, a one-time licence key keeps Pro: Personal USD 29, Business USD 59 per user.
